# Sistema de Gestión de Biblioteca

Taller 1 - Programación de Computadores III - UPC

## Autor

Jesús Manuel Martínez Baute - GRUPO 06  

## Descripción

Aplicación de consola en Java para gestionar clientes, libros y préstamos.

El sistema permite realizar operaciones CRUD sobre clientes y libros, además de registrar préstamos y gestionar la devolución de libros.

### Funcionalidades

- Crear, listar, buscar, actualizar y eliminar clientes.
- Crear, listar, buscar, actualizar y eliminar libros.
- Registrar préstamos.
- Listar préstamos.
- Registrar la devolución de libros.
- Controlar la disponibilidad de los libros.

### Tecnologías

- Java
- NetBeans
- ArrayList
- Programación Orientada a Objetos
